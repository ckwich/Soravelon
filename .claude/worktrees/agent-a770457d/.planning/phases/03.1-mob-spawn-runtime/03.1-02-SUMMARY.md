## What Was Built

### world/item_spawner.py

`create_item_from_template(item_def, location=None)` is the single public function.

- Typeclass map: `"equipment"` → `SoravelonEquipment`, `"container"` → `SoravelonContainer`, `"keyring"` → `SoravelonKeyringItem`, everything else → `SoravelonItem`
- Always sets: `db.item_type`, `db.weight`, `db.rarity`, `db.desc`, `db.value`, `db.equip_slot`
- Extra keys (not in `_RESERVED_KEYS`) set as `db.*` attrs (e.g., `damage_min`, `damage_max`, `capacity`)
- Reserved keys not duplicated into extra attrs loop

### world/area_builder.py changes

**`area.item(item_id, **kwargs)`** — new method after `npc()`. Stores item definition dict on `zone_obj.db.item_definitions` list using SaverDict copy pattern. Raises `AreaBuilderValidationError` if called before `zone()`.

**`area.named_mob()`** — refactored to thin wrapper around `area.spawn()` with:
- `is_named=True`
- `count_min=1, count_max=1`
- `respawn_minutes=120` (was 120 in old impl, preserved)
- `respawn_variance=30` (new field, sensible default)
- All existing kwargs forwarded: `tome_drop`, `spawn_condition`, `sequence`, `behavior`, `base_disposition`, `flee_threshold`, `prestige_modifier`

**`spawn()` dict** — expanded with D-13 fields:
- `is_named` (default False)
- `prestige_modifier` (default 1.0)
- `tome_drop` (default None)
- `spawn_condition` (default None)
- `sequence` (default [])

**`_set_room_attrs()`** — removed `named_mob_definitions` list initialization.

**`build()`** — removed `named_mob_registry.register_named_mob()` loop.

### server/conf/at_server_startstop.py changes

- Removed `named_mob_registry` from import in `_load_all_zones()`
- Removed `named_mob_registry.clear()` call
- Updated comment to not mention "named mob registries"
