```python
from dataclasses import dataclass

@dataclass
class ValidationError:

    field_path: str # dot-notation path e.g. "zone.zone_type", "rooms[2].room_type"
    message: str
```

2. Define these constants (copy exact values from area_builder.py — these become the authoritative source):
```python
VALID_ZONE_TYPES = {
    "ancient_forest", "plains", "mountain", "coastal",
    "underground", "imperial_city", "frontier", "node_active",
}
VALID_CONTINENTS = {"varath", "sorath", "veluana"}
VALID_NODE_TYPES = {
    "resonance", "thermal", "gravity", "temporal", "cognitive",
}
VALID_FACTION_TERRITORIES = {
    "imperial", "neutral", "warden", "kauroran",
    "contested", "hidden",
}
VALID_DIRECTIONS = {
    "north", "south", "east", "west",
    "northeast", "northwest", "southeast", "southwest",
    "up", "down", "in", "out",
}
VALID_ROOM_TYPES = {
    "path", "clearing", "ruins", "cave", "building",
    "underground", "node_center", "generic",
}
```

3. Implement `validate_zone(zone_data: dict) -> list[ValidationError]`. Input is a dict representing one .zone.json file's parsed content. Top-level keys: `zone` (dict), `rooms` (list[dict]), `exits` (list[dict]). Function checks:
   - zone.name: missing or falsy -> error
   - zone.zone_type: present but not in VALID_ZONE_TYPES -> error
   - zone.continent: present but not in VALID_CONTINENTS -> error
   - zone.node_type: present but not in VALID_NODE_TYPES -> error
   - zone.faction_territory: defaults to "neutral"; if present and not in VALID_FACTION_TERRITORIES -> error
   - For each room at index N: if room.get("room_type") and not in VALID_ROOM_TYPES -> error with field_path f"rooms[{N}].room_type"
   - For each exit at index N: if exit.get("direction") and not in VALID_DIRECTIONS -> error with field_path f"exits[{N}].direction"
   - Returns list of all ValidationError instances found (empty list = valid)
