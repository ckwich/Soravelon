Create `world/command_preprocessor.py`:

1. `resolve_prefix(raw_word, all_cmd_keys)`:
   - `raw_word = raw_word.lower().strip()`
   - Check exact match first: if raw_word in all_cmd_keys, return (raw_word, [])
   - Prefix scan: `matches = [k for k in all_cmd_keys if k.startswith(raw_word)]`
   - 0 matches → return (None, []) — let Evennia handle "command not found"
   - 1 match → return (matches[0], [])
   - 2+ matches → return (None, sorted(matches)) — sorted for consistent display (D-14)

2. `expand_alias(character, alias_key, raw_args)`:
   - Get `aliases = character.db.aliases or {}`
   - Return None if alias_key not in aliases
   - Get the expansion string: `expansion = aliases[alias_key]`
   - Token substitution helper `_substitute(cmd, parts, raw_args)`:
     - Replace `$*` and `$@` with `raw_args.strip()`
     - Replace `$1`, `$2`, ... `$N` with parts[0], parts[1], ... (no error if missing — leave as empty string)
   - Split expansion by ";": `commands = [c.strip() for c in expansion.split(";")][:3]` — D-16 cap of 3
   - `parts = raw_args.strip().split()`
   - Return `[_substitute(c, parts, raw_args) for c in commands if c]`

3. `_get_all_cmd_keys(character)`:
   - Collect keys from all cmdsets: iterate `character.cmdset.all()`, for each cmdset iterate `cmdset.commands`
   - Build set of all `cmd.key` and all entries in `cmd.aliases` (lowercase)
   - Return as sorted list for stable prefix matching
   - Note: this is called on every command input — keep fast; no DB queries inside

4. `preprocess_input(character, raw_string)`:
   - Split raw_string: `parts = raw_string.strip().split(None, 1)` → `[word, rest]`
   - `word = parts[0].lower(); raw_args = parts[1] if len(parts) > 1 else ""`
   - Get all cmd keys: `all_keys = _get_all_cmd_keys(character)`
   - **System command exact match check first (D-17, Pitfall 5):**
     - `if word in all_keys:` — exact match is a system command → skip alias lookup, go to prefix logic
     - But wait: exact match means no prefix expansion needed either → `return raw_string`
   - **Alias check** (only if word is NOT an exact system command match):
     - `expanded = expand_alias(character, word, raw_args)`
     - If expanded is not None: return expanded (list of 1-3 commands)
   - **Prefix resolution** (only if not an exact match and not an alias):
     - `resolved, matches = resolve_prefix(word, all_keys)`
     - If resolved: reconstruct `return f"{resolved} {raw_args}".strip()`
     - If matches (ambiguous): `character.msg(f"Did you mean: {', '.join(matches)}?")` → return None
     - If no matches: return raw_string (pass through — Evennia will say "unknown command")

**commands/cmd_alias.py** — new file:

```python
"""
Alias commands — create and remove personal command aliases.
"""
from evennia import Command

SYSTEM_COMMAND_KEYS = {
    "look", "l", "get", "drop", "give", "inventory", "inv", "i",
    "say", "whisper", "tell", "quit", "who", "help", "north", "south",
    "east", "west", "northeast", "northwest", "southeast", "southwest",
    "up", "down", "in", "out", "n", "s", "e", "w", "ne", "nw", "se", "sw",
    "alias", "unalias",
}

class CmdAlias(Command):
    """
    Create a personal command alias.

    Usage:
      alias <name> = <command>
      alias <name> = <cmd1>; <cmd2>; <cmd3>
      alias           (list all aliases)

    Examples:
      alias k = attack
      alias kill = attack $1
      alias buff = cast shield; cast haste; cast blessing

    Aliases support argument tokens: $1 $2 $* $@
    Maximum 3 chained commands per alias.
    Aliases cannot override system commands.
    """
    key = "alias"
    locks = "cmd:all()"
    help_category = "General"

    def func(self):
        if not self.args:
            # List aliases
            aliases = self.caller.db.aliases or {}
            if not aliases:
                self.caller.msg("You have no aliases set.")
                return
            lines = [f"  {k} = {v}" for k, v in sorted(aliases.items())]
            self.caller.msg("Your aliases:\n" + "\n".join(lines))
            return
        if "=" not in self.args:
            self.caller.msg("Usage: alias <name> = <command>")
            return
        name, _, expansion = self.args.partition("=")
        name = name.strip().lower()
        expansion = expansion.strip()
        if not name or not expansion:
            self.caller.msg("Usage: alias <name> = <command>")
            return
        # D-17: Cannot alias system commands
        if name in SYSTEM_COMMAND_KEYS:
            self.caller.msg(f"Cannot alias '{name}': that is a system command.")
            return
        # D-16: Warn if more than 3 chain parts
        parts = [p.strip() for p in expansion.split(";") if p.strip()]
        if len(parts) > 3:
            self.caller.msg("Aliases support a maximum of 3 chained commands. Excess commands will be ignored.")
        # Store — SaverDict copy pattern
        aliases = dict(self.caller.db.aliases or {})
        aliases[name] = expansion
        self.caller.db.aliases = aliases
        self.caller.msg(f"Alias set: {name} = {expansion}")


class CmdUnalias(Command):
    """
    Remove a personal command alias.

    Usage:
      unalias <name>
    """
    key = "unalias"
    locks = "cmd:all()"
    help_category = "General"

    def func(self):
        if not self.args:
            self.caller.msg("Usage: unalias <name>")
            return
        name = self.args.strip().lower()
        aliases = dict(self.caller.db.aliases or {})
        if name not in aliases:
            self.caller.msg(f"No alias '{name}' found.")
            return
        del aliases[name]
        self.caller.db.aliases = aliases
        self.caller.msg(f"Alias '{name}' removed.")
```
