  <action>
    **Create world/wander_system.py:**

    ```python
    """
    Wandering mob system — mobs with db.wander=True periodically move
    to a random connected room within their zone.

    Called by a global ticker (registered in at_server_startstop.py).
    Each tick, each wandering mob has a chance to move.
    """
    ```

    **wander_mob(mob):**
    1. Skip if `mob.db.wander` is not True
    2. Skip if mob is in combat (`mob.ndb.combat_script` is not None)
    3. Skip if mob has an active PatrolScript (check `mob.scripts.get("patrol_script")`)
    4. Skip if mob is dead (`mob.db.is_dead` or similar)
    5. Get all exits from mob.location
    6. Filter exits: destination must have same zone_id tag as mob's current room, destination must not have `no_mobs` tag
    7. If no valid exits, return False
    8. Pick random exit, move mob to destination: `mob.move_to(exit.destination, quiet=True)` then echo arrival to room
    9. After arrival, check disposition against players in new room (call `mob.check_disposition_on_arrival()` if it exists, or let the room's at_object_receive handle it)
    10. Return True

    **wander_tick():**
    1. Find all SoravelonMob objects with db.wander=True using Evennia's search: `evennia.search_tag("wander", category="mob_behavior")` — OR simpler: iterate all mobs. Since we don't have a wander tag, use `ObjectDB.objects.filter(db_typeclass_path__contains="SoravelonMob")` then check db.wander.
    2. Actually, most efficient: add a "wanderer" tag to mobs when db.wander is set by apply_mob_template. Then search by tag.
    3. For each wandering mob, roll a random chance (e.g., 40% chance per tick) to actually move — prevents all mobs moving every tick.
    4. Call wander_mob(mob) for those that pass the roll.

    **Simpler approach (preferred):** Don't use tags. The tick iterates zone objects, finds rooms with mobs that have db.wander=True. This is consistent with how spawn_tick works.

    **Register the tick:** Add `GLOBAL_TICKERS` entry or use `evennia.utils.repeat` in `at_server_startstop.py`. Tick interval: 60 seconds (mobs wander roughly once per minute with 40% chance = average once per 2.5 minutes).

    **Integration with mob_spawner.py:** In spawn_single_mob, after apply_mob_template, if mob.db.wander is True, add a tag: `mob.tags.add("wanderer", category="mob_behavior")`. This enables efficient querying.

    **Test file:** tests/test_wander_system.py using unittest.TestCase + MagicMock.
