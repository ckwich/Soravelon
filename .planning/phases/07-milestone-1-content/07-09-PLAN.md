    Create `world/areas/equipment_catalog.py` as a zone spec file that registers all equipment items via area.item(). These items are then available to vendors, loot tables, and crafting outputs by item_id.

    **Per D-35:** 3 material tiers with scaling stats:
    - Tier 1: Iron (base stats)
    - Tier 2: Steel (~1.5x iron stats)
    - Tier 3: Mithril (~2x iron stats, rare)

    **Per D-32:** 50+ items. Organize by slot:

    **Weapons (main_hand):**
    - Sword (balanced, strength scaling) — 3 tiers = 3 items
    - Dagger (fast, agility scaling) — 3 tiers
    - Mace (slow, strength scaling) — 3 tiers
    - Staff (two-handed, willpower scaling, per D-38) — 3 tiers
    - Greatsword (two-handed, strength scaling, per D-38) — 3 tiers
    - Greataxe (two-handed, highest damage, per D-38) — 3 tiers
    - Bow (ranged flavor only per D-32) — 3 tiers
    Total: ~21 weapons

    **Shields (off_hand, per D-39):**
    - Buckler (light, small armor_value) — 3 tiers
    - Kite Shield (heavy, larger armor_value) — 3 tiers
    Total: ~6 shields

    **Armor (head, chest, hands, legs, feet):**
    - Light set (leather — agility-friendly) — 5 slots x 3 tiers = 15
    - Heavy set (plate — strength-friendly) — 5 slots x 3 tiers = 15
    Total: ~30 armor pieces (some tiers may not have heavy plate)

    **Accessories (face, back, wrists, ring1/ring2, amulet):**
    - Cloak (back, various bonuses) — 2-3 items
    - Bracers (wrists, stat bonuses) — 2-3 items
    - Ring (ring1/ring2, small bonuses) — 3-4 rings
    - Amulet (amulet slot, willpower/perception) — 2-3 items
    - Face mask/goggles (face, perception/endurance) — 1-2 items
    Total: ~12 accessories

    Grand total: ~69 items (well over 50+)

    **Per D-42:** Each weapon has damage_min, damage_max, plus stat scaling:
    ```python
    area.item("iron_sword", key="Iron Sword", item_type="equipment",
              equip_slot="main_hand", damage_min=8, damage_max=14,
              stat_bonuses={"strength": 1}, material_tier=1,
              scaling_stat="strength",
              weight=3.0, rarity="normal", value=25,
              desc="A sturdy iron longsword with a simple crossguard.")
    ```

    **Per D-33:** Soft stat requirements — weapons work for anyone, scale better with matching stats. Implement via `scaling_stat` field on item definitions (no hard checks).

    **Per D-40:** Small stat bonuses on all equipment (+1 to +3 range depending on tier).
    **Per D-41:** No durability.
    **Per D-43:** No set bonuses. No procedural affixes.
    **Per D-36:** No weight enforcement (ignore encumbrance).

    **Per D-44:** Basic consumable potions (NOT equipment, item_type="consumable"):
    - "minor_healing_potion" — restores HP
    - "minor_stamina_potion" — restores stamina
    - "antidote" — cures poison
    - "bandage" — slow heal over time
    These are defined with use_effect field for future implementation.

    Zone spec uses a utility zone to hold all item definitions:
    ```python
    area.zone("equipment_catalog", "Equipment Catalog",
              zone_type="frontier", continent="varath")
    # No rooms — just item definitions
    ```
