5. `spawn_room_mobs(room)`:
   - spawned = 0
   - For each spawn_def in (room.db.spawn_definitions or []):
     - existing = _count_room_mobs(room, spawn_def)
     - needed = max(0, spawn_def.get("count_min", 1) - existing)
     - For _ in range(needed): call spawn_named_mob or spawn_single_mob per is_named flag; spawned += 1
   - Return spawned

6. `spawn_zone(zone_obj)`:
   - import evennia
   - rooms = evennia.search_tag(zone_obj.db.zone_id, category="zone_id")
   - Filter to rooms only (check hasattr(r, "db") and r.db.zone_id — exclude zone_obj itself)
   - Total = sum(spawn_room_mobs(room) for room in zone_rooms)
   - Return total

7. `_maybe_attach_patrol(mob, spawn_def, room)`:
   - from world.zone_scaling import get_zone_obj_for_room
   - zone_obj = get_zone_obj_for_room(room)
   - If not zone_obj or not zone_obj.db.patrol_definitions: return
   - Find patrol_def in zone_obj.db.patrol_definitions where patrol_def["mob_key"] == spawn_def["mob"]
   - If not found: return
   - Resolve route: for each room_id in patrol_def["route_room_ids"]: search_tag(room_id, category="room_id"), filter by zone_id match → get dbref int
   - from world.scripts.patrol_script import PatrolScript
   - mob.scripts.add(PatrolScript)
   - script = mob.scripts.get(key="patrol_script")[0]
   - script.db.route_ids = resolved_route_ids
   - script.db.patrol_def = patrol_def

8. `_schedule_respawn(spawn_def, room)`:
   - import random
   - base = spawn_def.get("respawn_minutes", 15) * 60
   - variance = spawn_def.get("respawn_variance", 5) * 60
   - delay = base + random.uniform(-variance, variance)
   - delay = max(delay, 30)  # minimum 30s floor
   - def _do_respawn():
       if _count_room_mobs(room, spawn_def) < spawn_def.get("count_max", 1):
           if spawn_def.get("is_named"):
               spawn_named_mob(spawn_def, room, is_respawn=True)
           else:
               spawn_single_mob(spawn_def, room)
   - from twisted.internet import reactor; reactor.callLater(delay, _do_respawn)
