```python
class CharacterQuest(models.Model):
    """
    Tracks a character's progress on a specific quest.
    Per D-01: character FK, quest_id (str), status, progress (JSONField dict), timestamps.
    Per D-04: Three terminal states: complete, failed, abandoned. Active = in-progress.
    """
    STATUS_CHOICES = [
        ("active", "Active"),
        ("complete", "Complete"),
        ("failed", "Failed"),
        ("abandoned", "Abandoned"),
    ]

    character = models.ForeignKey(
        "objects.ObjectDB",
        on_delete=models.CASCADE,
        related_name="character_quests",
    )
    quest_id = models.CharField(max_length=128, db_index=True)
    status = models.CharField(max_length=16, choices=STATUS_CHOICES, default="active")
    progress = models.JSONField(default=dict)  # {"kill_ash_wolf": 4, "collect_fang": 2}
    started_at = models.DateTimeField(auto_now_add=True)
    completed_at = models.DateTimeField(null=True, blank=True)

    class Meta:
        indexes = [
            models.Index(fields=["character", "status"]),
            models.Index(fields=["character", "quest_id"]),
        ]

    def __str__(self):
        return f"{self.character.db_key}:{self.quest_id}={self.status}"
```

Key functions to implement:

1. **_get_quest_spec(quest_id)** -- Search zone objects tagged "zone_object" (category "object_type") for quest_definitions containing quest_id. Return the spec dict or None. Guard per Pitfall 4.

2. **_normalize_quest_spec(quest_spec)** -- Convert flat format (objective_type/target/count) to objectives list format per Pitfall 1. If spec already has "objectives" key, return as-is. Otherwise, create single-item objectives list from flat fields. Also normalize "gather"/"recover"/"discover"/"craft"/"escort" to MVP types per Research mapping table.

3. **accept_quest(character, quest_id, quest_spec)** -- Per D-01/D-02/D-03. Check 5-active cap, one_chance lock, not already active. Create CharacterQuest with progress={} (empty dict). Return (True, message).

4. **abandon_quest(character, quest_id)** -- Per D-04. Set status="abandoned". Return (True/False, message).

5. **check_kill_objectives(character, mob)** -- Per D-07/D-19. Get mob.db.mob_template and mob.db.mob_id. Query active quests, for each check normalized objectives list for type="kill" where target matches template or named_id. Use F() expression for atomic increment on the progress JSONField key. After increment, call _check_quest_completion.

6. **check_collect_objectives(character, item)** -- Per D-08. Check item tags or item.db.item_tag. Same pattern as kill.

7. **check_investigate_objectives(character, room)** -- Per D-09. Check room.db.room_id against target. Complete = set progress key to 1. Room visit only (no search check for MVP simplicity).

8. **check_deliver_objectives(character, npc)** -- Per D-10. Check if character has item with matching tag AND npc matches target NPC.

9. **check_talk_to_objectives(character, npc)** -- Per D-11. Check npc.db.npc_id against target.

10. **_check_quest_completion(character, cq, quest_spec)** -- Check all objectives met. If complete: set status="complete", completed_at=now, pay rewards via execute_action (D-20), push OOB, if next_quest_id set ndb.pending_quest_offer (D-05).

11. **_pay_rewards(character, quest_spec)** -- Iterate rewards list, call execute_action for each.

12. **get_available_quest_for_npc(npc, character)** -- Per D-18. Get npc's npc_id. Search all quest_definitions for quest_giver matching npc_id. Filter out: already active, already complete (unless not one_chance), one_chance + failed. Return first available spec or None.

13. **get_active_quests(character)** -- Return active CharacterQuest queryset.

14. **get_quest_detail(character, quest_id)** -- Return dict with name, description, objectives with progress, rewards preview.

For progress tracking, use a dict keyed by a combination of objective type and target:

- Collect objective key: `"collect_{target}"`
