Extract a private helper per D-10 (in the same module):
```python
def _compute_raw_damage(attacker, weapon):
    """Compute base raw damage for character or mob attacker.
    
    Returns (raw_damage: int, element: str).
    """
    attacker_stats = attacker.db.base_stats
    if attacker_stats:
        strength = attacker_stats.get("strength", 10)
        if weapon:
            w_min = weapon.db.damage_min or BARE_HANDS_MIN
            w_max = weapon.db.damage_max or BARE_HANDS_MAX
            element = weapon.db.element or "physical"
        else:
            w_min = BARE_HANDS_MIN
            w_max = BARE_HANDS_MAX
            element = "physical"
        raw = random.randint(w_min, w_max) + int(strength * 0.5)
    else:
        raw_min = attacker.db.ref_damage_min or 8
        raw_max = attacker.db.ref_damage_max or 14
        raw = random.randint(raw_min, raw_max)
        element = attacker.db.element or "physical"
    return raw, element
```

Replace the two inline branches in resolve_attack (or whatever the calling function is) with:
```python
raw, element = _compute_raw_damage(attacker, weapon)
```

**2. status_effects.py — effect list search (lines ~197-201 and ~227-233):**

Both `_apply_stackable` and `_apply_non_stackable` contain:
```python
existing = None
for entry in effects:

        existing = entry
        break
```

And the non-stackable version also tracks index:
```python
existing = None
existing_idx = None
for idx, entry in enumerate(effects):
    if entry["type"] == effect_type:
        existing = entry
        existing_idx = idx
        break
```

Extract per D-10:
```python
def _find_effect(effects, effect_type):
    """Find an effect entry by type. Returns (entry, index) or (None, -1)."""
    for idx, entry in enumerate(effects):
        if entry["type"] == effect_type:
            return entry, idx
    return None, -1
```

Replace both loops:
- In _apply_stackable: `existing, _ = _find_effect(effects, effect_type)`
- In _apply_non_stackable: `existing, existing_idx = _find_effect(effects, effect_type)`
