  <action>
    Create world/oob_publisher.py as a NEW file. Module docstring: "OOB publisher — single hub for all
    server-to-client push data. All game systems import and call push_* functions here. Never call
    character.msg() for OOB directly from game logic."

    DEBOUNCE_INTERVALS dict (exact values per D-06 + Claude's Discretion from RESEARCH.md):
      "status_update": 2.0, "map_update": 0.5, "node_event": 0.0, "flight_progress": 1.0,
      "combat_update": 0.25, "quest_update": 5.0, "inventory_update": 1.0, "stat_update": 0.5

    Internal helpers (module-level private, _ prefix per convention):
    - _should_send(character, msg_type) -> bool: reads (character.ndb.oob_debounce or {}), compares
      time.monotonic() against last-sent; interval <= 0 always returns True
    - _mark_sent(character, msg_type): copies dict, sets [msg_type] = time.monotonic(), writes back
    - _send(character, msg_type, data): checks sessions.all(), calls _should_send, calls
      character.msg(**{msg_type: data}), calls _mark_sent

    push_status_update(character):
      Import get_character_context_packet from world.world_state (lazy import inside function).
      packet = get_character_context_packet(character)
      Assemble: {"dimensions": {k: packet.get(k+"_score") or 0.0 for k in
        ("reputation","network","bond","legacy","attunement")},
        "domains": packet.get("domain_scores") or {},
        "carried_scales": character.db.carried_scales or 0,
        "companion": {"id": character.db.companion_id, "type": character.db.companion_type,
          "tier": character.db.companion_tier}}
      Call _send(character, "status_update", data)

    push_stat_update(character):
      data = {"hp": None, "hp_max": None, "conditions": []}
      _send(character, "stat_update", data)

    push_map_update(character):
      Build map payload using evennia.search_tag(zone_id, category="zone_id").
      Filter results: only objects whose typeclass_path ends with "rooms.SoravelonRoom"
      (avoids exits, zone objects, mobs — per Pitfall 3).
      For fog_of_war: read character.location.db.fog_of_war or False.
      For visited: room_id in (character.db.visited_room_ids or set()).
      For node_state: room.tags.get(category="node_state").
      For exits: [{direction, destination_zone, cross_zone}] — cross_zone = dest zone_id != current zone.
      group_markers = _get_group_positions(character).
      _send(character, "map_update", data)

    _get_group_positions(character) helper:
      Import get_group_state from world.group_engine (lazy).
      Returns list of {room_id, member_name} for group members in same zone (not self).
      If no group: return [].

    push_node_event(character, zone_id, old_state, new_state):
      data = {"zone_id": zone_id, "old_state": old_state, "new_state": new_state}
      _send(character, "node_event", data)

    push_flight_progress(character, leg_index, total_legs, destination_name, disembark_available):
      data = {"leg_index": leg_index, "total_legs": total_legs,
              "destination_name": destination_name, "disembark_available": disembark_available}
      _send(character, "flight_progress", data)

    push_combat_update(character, data):
      _send(character, "combat_update", data)

    push_quest_update(character, data):
      _send(character, "quest_update", data)

    push_inventory_update(character):
      Import get_carry_state from world.inventory_helpers (lazy).
      Import get_inventory from world.inventory_engine (lazy, if such function exists —
      otherwise use character.contents filtered by item typeclass).
      data = {"items": [], "encumbrance": get_carry_state(character)}
      _send(character, "inventory_update", data)
      NOTE: items list is a stub — full implementation requires inventory_engine query in Phase 6.
      For now send empty list so the schema is live.

    Use `import time` at module top. All other imports are lazy (inside functions) to avoid
    circular imports — project convention.
