  <action>
**Dynamic ability help (per D-03, D-05):**

Create `commands/cmd_help.py` with a custom `CmdHelp` that extends Evennia's default help command. The approach: override `func()` to intercept the query, check if it matches an ability_id or ability name in ABILITIES, and if so render dynamic help text. Otherwise fall through to Evennia's standard help behavior.

Implementation:
1. `from evennia.commands.default.help import CmdHelp as EvenniaCmdHelp`
2. Create `class CmdHelp(EvenniaCmdHelp):`
3. Override `func(self)`:
   a. Get the raw query: `query = self.args.strip().lower()`
   b. If query is empty, call `super().func()` and return (show help index)
   c. Try to match query against ABILITIES:
      - Direct match: `ABILITIES.get(query)`
      - Name match: iterate ABILITIES values, check if `ability["name"].lower() == query`
   d. If ability found, format and display:
      ```
      |wAbility: {name}|n
      |xTier {tier} | {domain} | {effect_type}|n

      {description}

      |cResource:|n {resource_cost} {resource_type}
      |cCooldown:|n {cooldown} rounds
      |cScaling:|n {scaling_primary}{" / " + scaling_secondary if scaling_secondary else ""}
      {"|cCharge:|n " + str(charge_turns) + " turns" if charge_turns else ""}
      ```
   e. If no ability match, call `super().func()` to use standard help

4. Register in `commands/default_cmdsets.py` CharacterCmdSet:
   ```python
   from commands.cmd_help import CmdHelp
   self.add(CmdHelp())
   ```
   This overrides Evennia's default CmdHelp since it has the same key.

Import ABILITIES lazily inside func() to avoid import-time issues:
```python
from world.ability_registry import ABILITIES
```
