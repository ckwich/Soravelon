3. Add `at_repeat()` method (tick handler):
   - Check if event has expired: `if self.db.expires_at and time.time() > self.db.expires_at`
   - If expired, call `self.complete_event()`
   - Otherwise, call `self.on_event_tick()`
4. Add `on_event_tick(self)` method:
   - Base implementation: update `self.db.event_data["tick_count"]` incrementing by 1
   - Override point for subclasses
5. Add `complete_event(self)` method:
   - Set `self.db.event_data["completed"] = True`
   - Set `self.db.event_data["completed_at"] = time.time()`
   - Log completion
   - Call `self.stop()` to end the script
6. Add `log_state_change(self, old_state, new_state)` method:
   - Append to `self.db.event_data.setdefault("state_log", [])` a dict with old_state, new_state, timestamp
   - Useful for tracking world event progression
7. Import `time` and `logger` (from evennia.utils import logger) at top of file if not already present
