Functions:
- `set_ancestry(character, ancestry_id, coat=None)` — Returns (bool, str). Rejects if character.db.ancestry is already set. Validates ancestry_id in ANCESTRY_TRAITS. If selvar, requires coat in VALID_COATS. Sets character.db.ancestry. If selvar and coat, sets character.db.selvar_coat. Calls `_apply_starting_standings(character, ancestry_id)`. Returns True and confirmation message.
- `_apply_starting_standings(character, ancestry_id)` — Lazy imports `modify_standing` from `world.world_state`. Iterates ANCESTRY_STARTING_STANDING entries calling `modify_standing(character, faction_id, amount, "ancestry_starting")`. For selvar: iterates KNOWN_FACTIONS_AT_CREATION applying SELVAR_ALL_FACTIONS_PENALTY to each, then applies SELVAR_GUILD_OFFSET to "guilds".
- `get_ancestry_trait(character, trait_name, default=None)` — Reads character.db.ancestry, looks up ANCESTRY_TRAITS[ancestry_id], returns trait value or default. Convenience function for other modules.

IMPORTANT: modify_standing takes 4 args: (character, faction_id, amount, reason). Always pass a reason string like "ancestry_starting".

Module-level docstring explaining lazy-decay room flags, no global ticker.

Constants:
- `ROUND_DURATION_SECONDS = 3`
- `FLAG_VOCABULARY` dict with all 20 flags from vault doc. Each flag entry has: description (str), typical_duration (int), writers (list of str), readers (list of str). Include all 20 flags: charged, burning, frozen, toxic_air, resonant, void_touched, fading_life, blood_soaked, living_wood, fortified, scouted, disrupted, power_vacuum, unsettled, ancient_presence, still, shadow_marked, predator_kill, corrupted_death, node_critical, node_calming.
- `SENSE_PRIORITY` list — ordered from most significant to least: void_touched, node_critical, ancient_presence, resonant, corrupted_death, power_vacuum, toxic_air, burning, charged, frozen, shadow_marked, living_wood, predator_kill, fading_life, blood_soaked, disrupted, node_calming, unsettled, fortified, scouted, still.
- `SENSE_DISPLAY` dict mapping flag name to atmospheric one-liner string. Include all 20 entries plus None -> "". Exact text from vault doc.

Functions:
- `get_room_flags(room)` — Returns dict of {flag_name: rounds_remaining}. Reads room.ndb.room_state. If not set, returns {}. Calculates elapsed time since last_updated, computes rounds_passed = int(elapsed / ROUND_DURATION_SECONDS). If rounds_passed == 0, return copy of flags. Otherwise decay: subtract rounds_passed from each flag's remaining, remove expired (<=0). Respects duration == -1 as "persistent" (never decay). Write back decayed state. Return active flags dict.
- `add_room_flag(room, flag_name, duration=None)` — If flag_name not in FLAG_VOCABULARY, log warning via evennia.logger.log_warn and return (don't crash). Default duration from FLAG_VOCABULARY[flag_name]["typical_duration"]. Get current flags via get_room_flags(). Set flag to max of existing remaining vs new duration (refresh, don't shorten). Write back room.ndb.room_state.
- `remove_room_flag(room, flag_name)` — Get current flags, pop flag_name, write back.
- `get_dominant_flag(room)` — Get active flags. If none, check _room_qualifies_as_still(room) and return "still" or None. Iterate SENSE_PRIORITY, return first match. Fallback: max by rounds_remaining.
- `_room_qualifies_as_still(room)` — Check `room.ndb.last_activity` timestamp. If (time.time() - last_activity) > (ROUND_DURATION_SECONDS * 20), return True.

Import only `time` at module level. `evennia` imported lazily inside add_room_flag for logger.
